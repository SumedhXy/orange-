HOW TO RUN THIS DEMO IN 1 MINUTE:
1. Open https://wokwi.com/projects/new/esp32 in your browser.
2. In the "diagram.json" tab, REPLACE all existing text with the JSON CODE below.
3. In the "sketch.ino" tab, PASTE the code from "wokwi_sketch.ino".
4. In the "Library Manager" (libraries.txt tab), paste these two lines:
     Adafruit SSD1306
     Adafruit GFX Library
5. Click the green PLAY (Start Simulation) button!

WHAT YOU CAN DO DURING SIMULATION:
• Press the Red Pushbutton ("SIMULATE PEST") -> Triggers immediate pest alert, red LED,
  cabin buzzer, 1.5s solenoid spray burst, and Marathi WhatsApp advisory!
• Rotate the KY-040 Encoder -> Simulates tractor wheel odometry advancing down row.
  Every 5 meters, it arrives at the next tree!
• Move the HC-SR04 Distance Slider -> Detects tree trunk presence (< 140cm).
• If left untouched -> Auto-cruise drives tractor smoothly down Row 04 at 6.2 km/h.
